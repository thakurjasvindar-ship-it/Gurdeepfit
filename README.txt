GURDEEPFIT WEBSITE
==================

Files:
- index.html        Home/front page
- client-form.html  Separate client application page
- style.css         Responsive design
- script.js         Form handling
- images/           Your 3 uploaded photos

How to use:
1. Keep the folder structure unchanged.
2. Open index.html in a browser to preview.
3. Upload the whole folder to a static host such as GitHub Pages.

IMPORTANT:
The client form currently saves applications only in the browser's localStorage.
That means it is a working front-end form, but it does NOT automatically send client
data to Gurdeep Singh. Before using it with real clients, connect the form to a
secure backend/database or a reputable form service and add an appropriate privacy
notice/consent process.

The copy avoids promising guaranteed results; use verified client transformation
photos/testimonials only if you have permission and genuine records.
